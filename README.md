# UnlimitedPipe feeds

A catalog of useful feeds, updated every hour by a GitHub Actions workflow and served for free
by GitHub Pages. Built with [UnlimitedPipe](https://pypi.org/project/unlimitedpipe/).

**Browse and subscribe: https://fuyuki0.github.io/unlimitedpipe-feed-demo/**

Every feed also exists as JSON (same name, `.json`) carrying full UnlimitedPipe events with
provenance, so other pipelines can build on it: `unlimited rss https://fuyuki0.github.io/unlimitedpipe-feed-demo/ai-news.json`.

## How it works

Each file in [`feeds/`](feeds) is a complete pipeline: where to read, what to keep, where to
write. [`.github/workflows/unlimitedpipe-feeds.yml`](.github/workflows/unlimitedpipe-feeds.yml)
was generated by `unlimited publish feeds/*.yml` and runs them all every hour. What each feed
has already seen lives in `.unlimitedpipe/state/`, so every run adds only new items.

Items link to the original sources; titles and short summaries come from their feeds and APIs.

## Suggest a feed

Open an issue with a source (an RSS feed, an official API or a public page) and what to follow
in it. Or make your own: `pip install unlimitedpipe`, write a pipeline, `unlimited publish`.
