# AI news feed

AI and LLM stories from the Hacker News front page and Lobsters, filtered into one feed and
updated every hour by a GitHub Actions workflow. Built with
[UnlimitedPipe](https://pypi.org/project/unlimitedpipe/).

Subscribe in any feed reader:

- RSS: https://fuyuki0.github.io/unlimitedpipe-feed-demo/ai-news.xml
- JSON Feed (with full UnlimitedPipe events and provenance): https://fuyuki0.github.io/unlimitedpipe-feed-demo/ai-news.json

## How it works

[`feeds/ai-news.yml`](feeds/ai-news.yml) is the whole pipeline: read two feeds, keep items
that mention AI topics, drop duplicates, keep only items not seen before, write RSS and JSON
Feed files. [`.github/workflows/unlimitedpipe-ai-news.yml`](.github/workflows/unlimitedpipe-ai-news.yml)
was generated by `unlimited publish` and runs it hourly. The state that remembers which
stories were already seen lives in `.unlimitedpipe/state/`.

Make your own:

```bash
pip install unlimitedpipe
unlimited new https://some-blog.example -o feeds/my-feed.yml   # then write outputs to public/
unlimited publish feeds/my-feed.yml --every 1h
```

Items link to the original stories. Titles and short summaries come from the source feeds.
